# Mainfotech — Intercom × Clay Sample

This is a static HTML/CSS/JS sample combining:
- Intercom-inspired friendly light-mode structure
- Clay-inspired rounded, colorful visual cards
- Mainfotech blue as the technology accent
- Replaceable real-image areas

## Add your real images

Place these files in `assets/`:
- `hero.jpg`
- `service.jpg`
- `contact.jpg`

The page already contains placeholders and will automatically display your images when those files are added.

Open `index.html` in a browser.

## Logo
The supplied Mainfotech logo is included at `assets/mainfotech-logo.png` and is used in the navigation and footer.
